## Notes and caveats

- **Repository weight.** The videos dominate at roughly 118 MB, and the hero alone is ~87 MB
  across its two codecs. Nothing has been committed to git — the working tree is left dirty on
  purpose. If this size is unwanted, gitignore `public/sites/www-nscale-com-782295e3/root-8a5edab2/videos/` and rely on the committed
  downloader to fetch them on demand; the clone is fully reproducible from the script.
- **Two hero codecs, on purpose.** `…-vp9-chrome.webm` (22 MB) and `…-hevc-safari.mp4` (65 MB).
  Components list the WebM `<source>` first so Chrome and Firefox never pull the 65 MB HEVC file;
  only Safari falls through to it. Reversing that order would be a large, silent regression.
- **Filename convention.** Local names keep the Webflow asset hash prefix, lowercased, with
  `%20`/spaces collapsed to `-`. That prefix is what maps a local file back to its `<img src>`
  in the captured source DOM.
- **The `.riv` files are binary Rive artboards**, not images. The desktop platform stack loads
  `…nscale-stack_v2.riv` with artboard `Artboard` and state machine `LayerController`.
  `…_no-cursor.riv` is a second variant referenced by the bundle but not used by this page; it is
  kept for completeness.
